# Frontend variant — fixed baseline

Same three dials as the base skill. The difference: this variant does not infer them from
the brief — it starts from one fixed preset and only moves off it when the user explicitly says
so. Use it when consistency across runs matters more than per-brief accuracy, or when a project
already assumes this fixed baseline. Do not force it onto a brief that clearly wants a different
starting posture (a dashboard, a utility tool) — use the base skill's inference step instead.

## Fixed baseline

| Dial | Value | vs. inferring per brief |
|---|---|---|
| DESIGN_VARIANCE | 8 | skips the "guess from brief" step entirely |
| MOTION_INTENSITY | 6 | starts animated by default, not static |
| VISUAL_DENSITY | 4 | starts airy by default, not inferred |

Do not ask the user to edit these. Adapt only when they say something in chat that implies a
different value — then treat that as the new baseline for the rest of the session, not a one-off.

## Bundled stack conventions

This variant treats taste and stack setup as one pass, not two. Apply these alongside the dials:

- React/Next.js, Server Components by default; anything interactive (state, motion) isolated into
  its own `'use client'` leaf, never at the layout root.
- CSS Grid over flexbox percentage math for multi-column layout.
- `min-h-[100dvh]`, never `h-screen`, for full-height sections (iOS viewport jumping).
- Check the installed icon/animation library before adding one — same rule as godkit-lazy, just
  restated here because this variant is meant to be self-contained per job.

## Tiered recipes

Where the base skill says "guess the value, state the reason," this variant gives literal ranges
to land in:

| Dial | 1–3 | 4–7 | 8–10 |
|---|---|---|---|
| DESIGN_VARIANCE | centered, symmetric grid, equal padding | offset overlap, mixed aspect ratios | masonry, fractional grid columns, huge empty zones |
| MOTION_INTENSITY | hover/active only, no auto-animation | CSS transition cascades on load | scroll-driven choreography |
| VISUAL_DENSITY | huge section gaps, gallery feel | normal app spacing | tiny padding, hairline dividers instead of cards |

## Extra banned defaults

On top of the base list: purple/blue neon glow as the default accent, pure `#000000`
backgrounds, placeholder names that read as filler ("John Doe", "Acme Corp"), suspiciously round
numbers (`99.99%`, `50%`) in sample data, and centered hero text once DESIGN_VARIANCE is above 4.
