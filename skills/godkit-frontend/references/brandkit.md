# Frontend variant — brand identity board, image only

Generates a premium brand-identity board as an image — logo concept, color system, typography,
application mockups — laid out as one presentation deck. Image output only, no code, no
implementation. Use when the user wants a brand kit, identity board, logo concept deck, or
visual-world presentation for a product or company. For UI screens or web sections, use
`imagegen-web` / `imagegen-mobile` instead. This produces the reference, not a usable logo file.

One image, one brand argument. The deliverable is a grid deck — logo, color, type, and
application mockups laid out on one board — not a loose moodboard and not a literal usable logo
file.

## Process

1. **Infer brand strategy before touching the logo.** Category, audience, emotional promise, and
   a core metaphor. The logo concept has to trace back to this — a symbol picked before the
   strategy is decided is decoration, not identity.
2. **Pick a logo concept method** — one, or combine at most two: monogram fused with a metaphor
   (a letterform bent into the product's meaning), the product's core action turned abstract
   (build → scaffold, protect → shield, speak → waveform), two ideas fused into one reduced mark,
   or negative space carrying the meaning. Never assign a symbol at random.
3. **Pick a visual mode** matching the category — this sets palette and mood together, don't set
   them independently:

   | Category | Mode | Palette lean |
   |---|---|---|
   | Dev tool / infra / AI builder | Dark developer | near-black, monospace accents, one bright accent |
   | Growth / sales / automation | Dark operator | black + dark red/amber, glowing chips |
   | Wellness / climate / calm SaaS | Dark nature | deep green + lime, misty imagery |
   | Security / compliance / monitoring | Dark security | black/navy, shield/radar motifs |
   | Legal / trust / documents | Light editorial | warm ivory, paper texture, seals |
   | Beauty / fashion / hospitality | Luxury | ivory/stone/espresso, serif wordmark |
   | Voice / chat / audio | Voice | dark indigo + lilac, waveform motifs |
   | Music / events / creative tools | Cultural | halftone, bold accent, poster panels |

4. **Lay out the deck.** Default 3×3 grid, dark or light canvas, strong gutters, minimal text.
   One panel each for: logo cover, logo construction/breakdown, a digital application (browser
   chrome, app header, terminal), a one-line tagline, color system, typography specimen, a
   physical application (card, badge, packaging), an image-direction panel, and one system-detail
   panel (UI chips, command line, pattern). Vary panel loudness — not every panel is a hero panel;
   the board should have a quiet/functional/emotional/technical rhythm across nine cells.
5. **Hold one palette across every panel.** Base + one primary accent + one secondary accent +
   neutrals. The accent must repeat panel to panel — a system that resets its palette per panel
   isn't a system.

## Text discipline

Brand name, one tagline, one URL or command, 2-5 section labels — that's the ceiling. No lorem
ipsum, no paragraph copy, no dense fake body text. A tagline is one short specific line, not a
corporate slogan.

## Extra banned defaults

Same spirit as the base skill's list, applied to identity work: generic lightning-bolt or
random-animal logos, copied-famous-mark silhouettes, purple-blue AI gradient as the palette
default, full fake dashboards standing in for "digital application," a rainbow of unrelated
accent colors, corporate-PowerPoint layout instead of a presentation-board grid.
