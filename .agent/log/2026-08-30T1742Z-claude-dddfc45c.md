## Decisions

- Structural checks only. A "does this evidence look real" heuristic was rejected: it misfires
  forever and teaches agents to write around it. Judging evidence stays with `godkit-review`.
- The Stop hook enforces one rule of six. Blocking on everything turns a Stop hook into a wall,
  and `stop_hook_active` is the only thing between that and a stuck turn.
- Findings reuse the existing `no-exit` / `no-verify` / `resume-blocked` tags rather than a new
  taxonomy — `godkit-review` already named these three failures, this just mechanizes them.
- Scope was cut hard against what the external runtime offered. Its sandbox, memory, MCP, gateway,
  sub-agent runtime and channels all presuppose a service stack; adopting any would break the
  zero-dependency and no-network constraints. A GitHub issue/PR triage skill was portable and
  still cut — a different surface, and ~300 lines of prose to own forever.
