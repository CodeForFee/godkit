## Decisions

- Stack stays CommonJS, zero runtime dependencies. TypeScript would add a build step and force
  every hook path in `hooks/godkit-hooks.json` to be rewritten, in exchange for types that
  `checkJs` can give without either.
- Identity is enforced by shape, not by an allowlist of known model ids. An allowlist goes stale and
  then rejects the truth.
- `unrecorded` is a legitimate value for entries predating the rule. Guessing which model wrote a
  log from August would put a fabricated attribution in the permanent record.
- Version stays `1.0.0`: nothing has been published, so there is no released version to move from.
