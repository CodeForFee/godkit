## Bugs

- fixed B-012 — Windows CI red since before 2026-08-26 (8 tests), plus 1 added by T-011. Root
  cause was **two canonicalizers in one codebase**: plain `fs.realpathSync` leaves an 8.3 short
  name alone while `.native` and git both expand it, so roots and fixtures were two spellings of
  one directory that compared as different. Cut in `lib/paths.js` (one canonicalizer, exported),

  happening in the wild; found while tracing the above and fixed in the same cut because it is
  the same mistake.

  whole matrix rather than only where the bug first appeared.
- `lib/paths.js` keeps one plain `fs.realpathSync` as its `.native`-unavailable fallback; the
  invariant test exempts that file by path rather than by pattern.
